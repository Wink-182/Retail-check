# Retail Check — приложение для обхода розничных точек

Мобильное PWA-приложение для торговых представителей: чек-лист визита в точку
продаж ламината, фото стендов и выкладки, гео-отметка. Работает полностью без
интернета — все данные хранятся на телефоне.

**Никакого сервера.** Отчёт по визиту уходит в общий чат Telegram одним
нажатием: сначала читаемое сообщение, следом фотографии. Отдельной кнопкой
тот же визит отправляется архивом — на почту, в Teams, куда угодно.
Google-сервисы не используются.

## Состав проекта

| Файл | Назначение |
|---|---|
| `index.html`, `styles.css`, `app.js` | само приложение |
| `sw.js` | service worker — работа без сети |
| `manifest.webmanifest`, `icons/` | установка на главный экран |

## Как приходит отчёт

Каждый визит отправляется отдельно, своей кнопкой в списке.

**В Telegram** (кнопка с логотипом Telegram, с подтверждением) приходит
**читаемое сообщение**, а сразу за ним **фотографии** визита:

```
📍 Москва
🏪 Леруа Мерлен
ООО «Ромашка»
+7 916 123-45-67
👤 Сергей Новиков · 21.08.2026 10:55
🗺 Точка на карте

Сегмент магазина: Средний +
Коллекции Кастамону:
• CraftCore
• LaMoena
Стенды:
✅ Кастамону
❌ LaMoena
❌ CraftCore
```

Незаполненные пункты в сообщение не попадают.

**Архивом** (кнопка ✉️) — один ZIP-файл с именем вида
`RetailCheck_Москва Леруа Мерлен_2026-08-21_11-15.zip`, внутри:

- `отчёт.txt` — тот же читаемый отчёт, что уходит в Telegram;
- `RetailCheck_….csv` — таблица для Excel (кодировка и разделители
  подобраны под русский Excel);
- `фото/…` — все снимки визита.

На iPhone архив уезжает прямо в письмо через меню «Поделиться».
На Android Chrome запрещает отдавать архивы в это меню, поэтому файл
сохраняется в «Загрузки» — его нужно прикрепить к письму вручную.

## Публикация на GitHub Pages (один раз)

1. Зарегистрируйтесь на [github.com](https://github.com), если аккаунта нет.
2. Создайте репозиторий (кнопка **New repository**), например `retail-check`,
   видимость **Public**.
3. Загрузите файлы проекта одним из способов:
   - **через браузер:** в пустом репозитории нажмите «uploading an existing file»
     и перетащите все файлы и папку `icons`;
   - **через git:** `git remote add origin <URL репозитория>` и `git push -u origin main`
     (локальный репозиторий уже подготовлен).
4. В репозитории: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`. Сохраните.
5. Через одну-две минуты приложение доступно по адресу
   `https://<логин>.github.io/retail-check/` — эту ссылку раздайте коллегам.

После любых изменений файлов просто загрузите их заново (или `git push`) —
телефоны подхватят обновление при следующем открытии с интернетом.

## Установка на телефоны коллег

1. Откройте ссылку на телефоне.
2. **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   **iPhone (Safari):** кнопка «Поделиться» → «На экран “Домой”».
3. В приложении: **⚙ Настройки** → указать имя. Названия точек, городов
   и юрлиц приложение запоминает само и подсказывает при следующем вводе.

## Как пользоваться

1. Пришли в точку → **«Новый визит»**. Координаты фиксируются автоматически.
2. Заполнить блок «Точка продаж» (магазин, юрлицо, телефон), город, чек-лист,
   сфотографировать стенды → **«Сохранить визит»**. Город подставляется
   из прошлого визита. Заполнять всё необязательно: визит сохранится
   с любыми пустыми полями, дополнить его можно позже.
3. Интернет в магазине не нужен — визиты копятся на телефоне со статусом
   «Не отправлен», в списке они сгруппированы по городам.
4. У каждого визита четыре кнопки: **✎ изменить**, **Telegram**,
   **✉️ архивом**, **🗑 удалить**. Перед отправкой в Telegram приложение
   переспрашивает, чтобы отчёт не ушёл случайным нажатием. Отправлять можно
   по одному, хоть сразу из точки, хоть все вечером — отправленные
   помечаются «Отправлен». Если потом поправить такой визит, к пометке
   добавится «отредактирован»: видно, что отправленную версию изменили
   и её стоит отправить заново.
5. Ненужные визиты удаляются кнопкой 🗑: фотографии занимают место
   на телефоне, поэтому старые отчёты стоит чистить.

## Координаты точки

Координаты записываются **один раз** — в момент, когда сотрудник создаёт визит,
то есть находясь в магазине. Если он потом откроет отчёт дома, чтобы дополнить
чек-лист, координаты **не обновятся**: в Telegram уйдёт адрес магазина, а не дома.

Поправить их можно вручную — кнопка **«Изменить»** рядом с отметкой:

- вставить координаты в поле («55.751244, 37.618423») — понимает и запятую
  как десятичный разделитель;
- вставить туда же **ссылку из Яндекс.Карт или Google Карт** — координаты
  вытащатся из неё сами. Кнопка «Найти точку на карте» открывает карту
  с поиском по городу и названию магазина: находите точку, нажимаете на неё,
  копируете координаты;
- «Взять моё текущее местоположение» — с отдельным предупреждением, что
  запишется место, где сотрудник находится **сейчас**;
- очистить поле и сохранить, чтобы убрать координаты совсем.

В отчёте видно, откуда координаты: «±12 м» — определены телефоном,
«указано вручную» — вписаны руками.

## Отправка в Telegram одним нажатием (по желанию)

Самый быстрый способ доставки: отчёт улетает в заранее заданный чат, без
меню «Поделиться» и без ограничений на архивы. Бесплатно, ничего согласовывать
не нужно. Настраивается один раз:

1. **Создать бота.** В Telegram напишите [@BotFather](https://t.me/BotFather)
   команду `/newbot`, придумайте имя. В ответ придёт **токен** вида
   `123456789:AAE…` — скопируйте его целиком.
2. **Создать чат для отчётов.** Проще всего — группа: создайте её, добавьте
   туда бота и коллег-получателей, напишите в группе любое сообщение.
   (Можно и просто переписку с ботом — тогда отчёты будут приходить вам лично;
   в этом случае напишите боту `/start`.)
3. **В приложении:** ⚙ Настройки → раздел «Отправка в Telegram» → вставить
   токен → нажать **«Определить ID чата»** (подставится автоматически из
   последнего сообщения) → **«Проверить связь»** — в чат придёт тестовое
   сообщение → **«Сохранить настройки»**.

После этого кнопка ✈️ на каждом визите отправляет его в чат: сначала текст
отчёта, следом фотографии.

Ограничения: нужен интернет в момент отправки; в сообщение помещается
до 4000 знаков (обычный визит — намного меньше). Токен хранится только на телефоне
сотрудника — но это общий секрет: у кого он есть, тот может писать от имени
бота, поэтому не публикуйте его.

## Сбор отчётов в одну таблицу (для руководителя)

Отчёты в Telegram удобно читать, но для аналитики нужна таблица. Соберите её
из csv-файлов, которые лежат в присланных архивах:

1. Заведите папку в OneDrive, например `Retail Check/Отчёты`, и складывайте
   туда csv из архивов.
2. В Excel: **Данные → Получить данные → Из файла → Из папки** → укажите папку
   с csv-файлами → **Объединить и загрузить**. Получится общая таблица по всем
   сотрудникам и визитам.
3. Дальше обновление в один клик: **Данные → Обновить всё** — Excel сам
   подхватит новые файлы из папки.

## Как изменить чек-лист

Вопросы описаны в начале файла `app.js`, массив `CHECKLIST`. Типы полей:

- `yesno` — Да/Нет;
- `number`, `text`, `textarea` — свободный ввод;
- `select` — один вариант из `options`;
- `multi` — несколько вариантов из `options` (списки конкурентов, коллекций);
  в `highlight` можно перечислить варианты, которые подсветить;
- `percents` — проценты по полям `fields`, остаток до 100% считается сам;
- `checkgroup` — галочки есть/нет по списку `items` (стенды);
- `ratinggroup` — для каждого из `items` один вариант из `options` (знание брендов).

Колонки в csv формируются автоматически из этого списка. После правок
увеличьте версию `VERSION` в `sw.js` (например, `rc-v8`), чтобы телефоны
обновили кэш. Если чек-лист изменился, старые и новые csv будут отличаться
колонками — сводную таблицу в Excel нужно будет пересобрать.

## Ограничения

- До 50 фото на визит; фото сжимаются до ~1400 px, чтобы отправка не висла
  на мобильном интернете. В Telegram они уходят альбомами по 10 штук.
- Гео-отметка требует разрешения на геолокацию; при отказе визит сохранится
  без координат.
- Приложению нужен HTTPS (GitHub Pages его даёт автоматически) — без него
  не работают камера, геолокация и офлайн-режим.
